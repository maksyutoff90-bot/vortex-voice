# Vortex Voice

Гостевые голосовые комнаты и показ экрана через браузер. Аудио и изображение передаются WebRTC напрямую между участниками; сервер нужен только для входа в комнату и обмена служебными сообщениями.

## Локальный запуск

```powershell
Copy-Item .env.example .env
npm.cmd start
```

Откройте `http://localhost:3000`. Для локальной проверки TURN необязателен: браузер доверяет `localhost`.

## Бесплатный публичный запуск: Render + Open Relay

1. Создайте бесплатный аккаунт на [Metered Open Relay](https://www.metered.ca/tools/openrelay/) и возьмите `username`, `password` и список TURN URL.
2. Создайте новый GitHub-репозиторий и загрузите в него этот проект. Файл `.env` не загружайте.
3. Войдите в [Render](https://render.com/), выберите **New → Blueprint**, подключите репозиторий и подтвердите `render.yaml`.
4. На форме настройки Render заполните секретные переменные `TURN_URLS`, `TURN_USERNAME` и `TURN_CREDENTIAL` данными из Open Relay. Нажмите **Apply**.
5. После статуса **Live** откройте адрес `https://…onrender.com`: он уже защищён HTTPS. Создайте комнату и отправьте ссылку друзьям.

Бесплатный Render засыпает после 15 минут без трафика; первый заход после простоя может занять примерно минуту. Для нескольких друзей это удобный тестовый вариант. Open Relay даёт 20 ГБ TURN-трафика в месяц — расход появляется только если прямое P2P-соединение между участниками недоступно.

## Безопасность и ограничения MVP

- Ссылка на комнату даёт вход любому, кому её переслали. Не используйте её для приватных встреч.
- Показ экрана и звук требуют HTTPS вне `localhost`; Render обеспечивает его автоматически.
- Текущая P2P-схема рассчитана на небольшие комнаты (2–6 человек). Для больших каналов нужен медиасервер SFU, например LiveKit.
